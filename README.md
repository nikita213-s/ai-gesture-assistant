# 🤖 AI Gesture Assistant

A real-time **AI-powered gesture recognition assistant** built with **Python**, **MediaPipe**, **OpenCV**, and **Tkinter**.  
It detects hand gestures from your webcam and **speaks** the recognized gesture using a **text-to-speech voice engine**.  

This project combines **computer vision**, **machine learning**, and **human–computer interaction** into a simple, interactive dashboard app.

---

## 🧠 Features

✅ Real-time hand gesture detection using MediaPipe  
✅ Predicts gestures with a trained machine learning model  
✅ Speaks recognized gestures aloud (Windows SAPI voice)  
✅ Live confidence and prediction display  
✅ Beautiful Tkinter-based GUI dashboard  
✅ History log of recent gestures  
✅ Mute / Unmute and Start / Stop controls
